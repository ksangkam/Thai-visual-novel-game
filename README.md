# พลายงาม : กำเนิดแห่งชะตา

เกม Visual Novel เพื่อการเรียนรู้วรรณคดีไทย เรื่องขุนช้างขุนแผน ตอนกำเนิดพลายงาม

## สถานะ

**สถานะ: พร้อม deploy เป็นเว็บ static** หน้าจอ เมนูเรื่อง บทสนทนา ตัวเลือก แบบทบทวน ผลคะแนน และคลังคำศัพท์เชื่อมกับข้อมูลโครงการแล้ว

Phase 2–5 เสร็จสำหรับรุ่นต้นแบบนี้ ภาพทั้งหมดจาก `pics/assets` เชื่อมใช้งานตามคำอนุมัติ: พื้นหลัง 9 ภาพ Event CG 4 ภาพ Character Sheet 7 ภาพ Sprite 30 ภาพ และ UI SVG 7 ภาพ

## โครงสร้าง

- `docs/` แผนงานและเอกสารโครงการ
- `public/assets/` ภาพพื้นหลัง ตัวละคร และส่วนติดต่อผู้ใช้
- `index.html`, `src/app.js` หน้าจอและ game flow
- `src/components/` ส่วนติดต่อผู้ใช้ที่นำกลับมาใช้ซ้ำ
- `src/engine/` ระบบฉาก บทสนทนา ตัวเลือก คะแนน บันทึก และคำศัพท์
- `src/data/` ข้อมูลฉากและเนื้อหาที่แยกจากระบบเกม
- `src/styles/` รูปแบบและธีมของเกม

## เตรียมและเปิดไฟล์สำหรับ deploy

รัน `python scripts/deploy/build_static.py` เพื่อสร้างโฟลเดอร์ `dist/` ที่มีเฉพาะไฟล์ runtime และ assets ที่ใช้ จากนั้นตรวจไฟล์ deploy ด้วย `python -m http.server 8000 --directory dist` แล้วเข้า `http://localhost:8000`.

อัปโหลด **เนื้อหาภายใน `dist/`** ไปยัง static hosting โดยวาง `index.html` ที่ root ของเว็บไซต์ ดูขั้นตอนใน `docs/DEPLOY.md` และผลตรวจใน `docs/QA_REPORT.md`.

## ขั้นตอนถัดไป

ขอบเขตถัดไปคือการเลือกผู้ให้บริการ hosting และเผยแพร่เว็บไซต์จริง; ไฟล์ deploy พร้อมอยู่ใน `dist/`.
