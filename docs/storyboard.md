# Storyboard — พลายงาม : กำเนิดแห่งชะตา

## ฐานข้อมูลและข้อจำกัดแหล่งอ้างอิง

ข้อเท็จจริงหลักในเอกสารนี้สังเคราะห์จากคู่มือ สพฐ. “หน่อเนื้อเชื้อไขในวรรณคดีไทย” (ระบุว่าอ้างหนังสือเรียนวรรณคดีลำนำ ป.6) และนามานุกรมวรรณคดีไทย ศูนย์มานุษยวิทยาสิรินธร; ลำดับฝากขรัวนากตรวจสอบประกอบกับบทความวิชาการ ม.บูรพา พ.ศ. 2568 ที่ยกข้อความจากหนังสือเรียน สพฐ. พ.ศ. 2564 หน้า 67. แหล่งเหล่านี้เป็นเรื่องย่อ/การอธิบาย ไม่ใช่การเทียบชำระบทเสภาฉบับเต็มแบบบรรทัดต่อบรรทัด จึงไม่อ้างว่าเป็นการตรวจสอบต้นฉบับฉบับพิมพ์เต็มแล้ว

**จุดที่ยังต้องยืนยัน:** (1) ผู้ใช้ยังไม่ได้เลือกฉบับต้นฉบับหลัก; (2) คำอธิบายเกมเดิมให้พลายงามถามทางเด็ก/ชาวบ้าน แต่แหล่งที่ตรวจไม่ยืนยันเหตุการณ์นั้น จึงยังไม่นำ NPC ดังกล่าวเข้าฉาก; (3) Outline ระบุฝากไว้กับขรัวนากและแยกการเดินทางเป็นฉาก แต่เรื่องย่อ SAC ย่อข้ามช่วงนี้ ขณะที่บทความ ม.บูรพาระบุว่ามีจริง; (4) เกมจบที่พบย่า ส่วนแหล่งอ้างอิงเล่าต่อถึงพิธีรับขวัญและพบขุนแผนภายหลัง จึงตัดไว้เป็นขอบเขตเกม ไม่อ้างว่าเป็นจุดจบของตอนวรรณคดี

## Storyboard 8 ฉาก

### scene01 — กำเนิดพลายงาม

- **ลำดับ/เวลาอ่าน:** 1/8; ประมาณ 3 นาที
- **เป้าหมาย:** LO1
- **สรุป (เรียบเรียง):** วันทองคลอดลูกชายชื่อพลายงาม เด็กเติบโตในเรือนขุนช้าง ก่อนที่ความคล้ายขุนแผนจะกลายเป็นชนวนความขัดแย้ง
- **ฉากหลัง:** `bg_scene01` — วันทองให้กำเนิดบุตรชายในเรือนของขุนช้าง ตั้งชื่อว่าพลายงาม; ฉากเปิดแนะนำความสัมพันธ์ของพ่อแม่และลูกโดยไม่ยกกลอนต้นฉบับ
- **เวลา/บรรยากาศ:** กลางวัน / อบอุ่นแต่มีเงาความไม่มั่นคงในครอบครัว
- **ตัวละครและตำแหน่ง:** wantong — กลางภาพ อุ้มทารก; phlai_ngam — อ้อมแขนวันทอง; khunchang — ฉากหลังด้านขวา
- **สีหน้า:** wantong = happy, phlai_ngam = normal, khunchang = normal
- **เอฟเฟกต์:** แสงอุ่นผ่านช่องหน้าต่าง, ผ้าม่านเคลื่อนไหวเบา ๆ
- **การเปลี่ยนฉาก:** ค่อย ๆ เลื่อนเวลาไปเมื่อพลายงามเติบโตเป็นเด็กชาย

### scene02 — ความแค้นของขุนช้าง

- **ลำดับ/เวลาอ่าน:** 2/8; ประมาณ 3 นาที
- **เป้าหมาย:** LO1, LO2
- **สรุป (เรียบเรียง):** ขุนช้างแน่ใจว่าพลายงามเป็นลูกขุนแผน ความแค้นจึงนำไปสู่อุบายในฉากถัดไป
- **ฉากหลัง:** `bg_scene02` — เมื่อพลายงามโตขึ้น ขุนช้างสังเกตเห็นความคล้ายขุนแผนและตระหนักว่าเด็กไม่ใช่บุตรของตน
- **เวลา/บรรยากาศ:** บ่าย / อึดอัดและตึงเครียด
- **ตัวละครและตำแหน่ง:** phlai_ngam — ด้านซ้าย กำลังทำกิจวัตร; khunchang — กลางภาพ มองจากด้านหลัง; wantong — ฉากหลัง
- **สีหน้า:** phlai_ngam = normal, khunchang = angry, wantong = worried
- **เอฟเฟกต์:** เงาพาดบนใบหน้าขุนช้าง, เสียงลมเบา
- **การเปลี่ยนฉาก:** เฟดจากสายตาขุนช้างไปยังทางออกนอกเรือน

### scene03 — อุบายกลางป่า

- **ลำดับ/เวลาอ่าน:** 3/8; ประมาณ 3 นาที
- **เป้าหมาย:** LO1, LO2, LO4
- **สรุป (เรียบเรียง):** อุบายพาพลายงามเข้าป่านำไปสู่การทำร้ายและการถูกทิ้งไว้ แต่เกมเล่าอย่างไม่โจ่งแจ้ง
- **ฉากหลัง:** `bg_scene03` — ขุนช้างลวงพลายงามไปเที่ยวป่าและทำร้ายจนสลบ จากนั้นทิ้งร่างไว้ใต้ขอนไม้ โดยไม่แสดงภาพความรุนแรง
- **เวลา/บรรยากาศ:** พลบค่ำ / เปลี่ยวและกดดัน
- **ตัวละครและตำแหน่ง:** phlai_ngam — กลางทางป่า; khunchang — ด้านขวา
- **สีหน้า:** phlai_ngam = worried, khunchang = angry
- **เอฟเฟกต์:** เงาต้นไม้ยาว, ภาพค่อย ๆ มืดลงก่อนเหตุทำร้าย, ไม่มีเลือดหรือบาดแผลให้เห็น
- **การเปลี่ยนฉาก:** จางภาพสู่ความมืด แล้วปรากฏแสงจันทร์

### scene04 — ผู้ช่วยเหลือในเงามืด

- **ลำดับ/เวลาอ่าน:** 4/8; ประมาณ 3 นาที
- **เป้าหมาย:** LO1, LO2
- **สรุป (เรียบเรียง):** โหงพรายช่วยพลายงามให้ฟื้น และไปเข้าฝันว่าวันทองจะได้รู้ตำแหน่งของลูก
- **ฉากหลัง:** `bg_scene04` — ผีพรายบริวารของขุนแผนช่วยให้พลายงามฟื้นและพ้นจากขอนไม้ ก่อนทำให้วันทองรู้เหตุที่เกิดขึ้นผ่านความฝัน ตามเรื่องย่อแหล่งอ้างอิง
- **เวลา/บรรยากาศ:** กลางคืน / ลึกลับแต่ปลอดภัยขึ้น
- **ตัวละครและตำแหน่ง:** phlai_ngam — กลางภาพใต้แสงจันทร์; hongphrai — ขอบภาพในหมอก; wantong — ปรากฏในภาพฝันช่วงท้าย
- **สีหน้า:** phlai_ngam = surprised, hongphrai = normal, wantong = worried
- **เอฟเฟกต์:** หมอกบาง, แสงจันทร์, ประกายเหนือธรรมชาติแบบนุ่มนวล
- **การเปลี่ยนฉาก:** แสงจันทร์เปลี่ยนเป็นแสงก่อนรุ่งเช้า

### scene05 — ความจริงจากปากแม่

- **ลำดับ/เวลาอ่าน:** 5/8; ประมาณ 4 นาที
- **เป้าหมาย:** LO1, LO2
- **สรุป (เรียบเรียง):** วันทองพบพลายงามและบอกความจริงเรื่องบิดา ความรักและความห่วงใยผลักให้เธอหาทางปกป้องลูก
- **ฉากหลัง:** `bg_scene05` — วันทองตามหาพลายงาม พบลูก และเปิดเผยว่าขุนแผนคือบิดา พร้อมอธิบายว่าขุนช้างทำร้ายเขา
- **เวลา/บรรยากาศ:** ใกล้รุ่ง / เศร้ากังวลแล้วคลายเป็นอบอุ่น
- **ตัวละครและตำแหน่ง:** wantong — ซ้าย คุกเข่าเข้าหาลูก; phlai_ngam — ขวา นั่งพัก
- **สีหน้า:** wantong = sad, phlai_ngam = worried
- **เอฟเฟกต์:** แสงรุ่งอรุณ, ลดหมอกเมื่อแม่ลูกพบกัน
- **การเปลี่ยนฉาก:** ตัดไปยังวัดใกล้บ้านในช่วงกลางคืน

### scene06 — การจากลาและฝากไว้ที่วัด

- **ลำดับ/เวลาอ่าน:** 6/8; ประมาณ 3 นาที
- **เป้าหมาย:** LO1, LO2, LO4
- **สรุป (เรียบเรียง):** วันทองจัดให้พลายงามอยู่ในความดูแลของขรัวนากชั่วคืน เพื่อปกป้องลูกก่อนให้เดินทางต่อ
- **ฉากหลัง:** `bg_scene06` — วันทองพาพลายงามไปฝากกับขรัวนากที่วัดจนรุ่งเช้า แล้วรีบกลับบ้าน; ฉากนี้อ้างอิงคำอธิบายในงานวิชาการที่ยกข้อความจากหนังสือเรียน สพฐ. 2564

### scene07 — เส้นทางสู่เมืองกาญจนบุรี

- **เอฟเฟกต์:** แสงเช้า, ทางเดินทอดไปขอบฉาก

## แหล่งอ้างอิงและข้อจำกัด

1. สำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน, *หน่อเนื้อเชื้อไขในวรรณคดีไทย* (คู่มือการเรียนการสอนวรรณคดีไทย; อธิบายบทเรียน “การเดินทางของพลายน้อย”), [PDF](https://academic.obec.go.th/images/document/1635912279_d_4.pdf).
2. ศูนย์มานุษยวิทยาสิรินธร, “ขุนแผน,” *นามานุกรมวรรณคดีไทย*, [เรื่องย่อและประวัติตัวละคร](https://thailitdir.sac.or.th/character-detail.php?n_id=2597). ใช้ยืนยันชาติกำเนิด อายุโดยประมาณ เหตุการณ์ในป่า โหงพราย และการไปบ้านทองประศรี.
3. วารสารวิชาการมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยบูรพา, ปี 33 ฉบับ 2 (พ.ค.–ส.ค. 2568), PDF หน้า 49–50, [บทความ](https://so06.tci-thaijo.org/index.php/husojournal/article/download/278918/190414/1257648). อธิบายการฝากพลายงามกับขรัวนากถึงรุ่งเช้าและยกข้อความจากหนังสือเรียน สพฐ. 2564 หน้า 67.
4. กรมศิลปากร/หอสมุดแห่งชาติ, *เสภาเรื่องขุนช้าง-ขุนแผน ฉบับหอสมุดแห่งชาติ*, [รายการคลังดิจิทัล](https://digital.nlt.go.th/dlib/items/show/18856). ใช้ตรวจประวัติการแต่งและความหลากหลายของผู้ประพันธ์; ไม่ได้เทียบกลอนฉบับเต็มในงานนี้.

**ยังต้องยืนยันก่อนตรึงเนื้อหา:** ผู้ใช้ยังไม่ได้เลือกฉบับต้นฉบับหลัก แหล่งที่ใช้ส่วนหนึ่งเป็นเรื่องย่อ/คำอธิบาย ไม่ใช่การเทียบฉบับเต็ม; การถามทางจากเด็กหรือชาวบ้านตาม Outline ยังไม่ยืนยัน จึงไม่สร้าง NPC หรือเหตุการณ์นั้นขึ้นมา; บางเรื่องย่อข้ามฉากขรัวนาก แต่บทความวิชาการอ้างหนังสือเรียนที่มีฉากดังกล่าว; แหล่งอ้างอิงเล่าต่อถึงพิธีรับขวัญและพบขุนแผนหลังฉากพบย่า ซึ่งอยู่นอกตอนจบที่กำหนดสำหรับเกมนี้. บทพูดทั้งหมดเป็นบทสนทนาเกมที่เขียนใหม่ ไม่ใช่คำประพันธ์ต้นฉบับ.
