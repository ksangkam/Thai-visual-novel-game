# Phase 3 — UI/UX

## แนวคิดภาพรวม

- **สี:** ครามหมึก `#17253C`, น้ำเงินราตรี `#111827`, แดงชาด `#5D2028`, ทองเก่า `#D8B56E`, และสีงาช้าง `#F3EAD6`
- **ตัวอักษร:** Pridi สำหรับชื่อเรื่อง/หัวฉากที่ชวนให้นึกถึงสิ่งพิมพ์วรรณคดี; Anuphan สำหรับเนื้อหาและคำสั่ง เพื่อให้อ่านไทยบนจอได้ชัด; มี Tahoma เป็น fallback
- **องค์ประกอบ:** ภาพฉากเต็มพื้นที่ด้านบนกับ sprite ด้านหน้า; แผงบทสนทนาทองแดง/แดงเข้มด้านล่างใช้กรอบ SVG ของโครงการ; หน้าเมนูวางชื่อเรื่องทับภาพหลักพร้อมตราประทับเล็กเป็นจุดจำ
- **หลักการ:** ให้เรื่องและภาพเป็นศูนย์กลาง จำกัดตัวควบคุมให้เข้าใจง่าย อ่านได้ทั้งเมาส์และคีย์บอร์ด และรองรับหน้าจอเล็ก

## หน้าจอในขอบเขตที่ทำแล้ว

### Main Menu

ใช้พื้นหลังเมนูจริง ชื่อเรื่องและคำโปรย ปุ่มเริ่มเรื่อง ปุ่มเลือกฉาก และทางเข้าคลังคำศัพท์

### Story Screen

ใช้พื้นหลังฉาก, sprite ตัวละครตาม expression ที่กำหนด, ภาพ CG ประกอบ, ป้ายชื่อผู้พูด, บทพูด, progress bar, scene selector, choice sheet พร้อม feedback และทางเข้าคลังคำศัพท์

### คลังคำศัพท์และสารบัญ

แผงด้านข้างแสดงคำศัพท์ทั้งชุดพร้อมคำอ่าน/ความหมาย และสารบัญ 8 ฉากพร้อมเวลาอ่านและเรื่องย่อ

## สถานะการทำงาน

ไฟล์หน้าจออยู่ใน `index.html`, `src/app.js`, และ `src/styles/phase3.css` ข้อมูลโหลดจาก `data/` โดยตรง คะแนน ตัวเลือกที่ตอบ และฉากล่าสุดเก็บใน localStorage ของเบราว์เซอร์

## งานต่อใน Phase 3

สร้าง quiz/result screen เป็น flow ที่แยกชัดเจน, เพิ่มหน้า settings/accessibility ถ้าจำเป็น, ทบทวนเนื้อหากับองค์ประกอบฉาก และตรวจ layout บนเดสก์ท็อป/แท็บเล็ต/มือถือผ่าน browser preview ก่อนส่งมอบ Phase 3
