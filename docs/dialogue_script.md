# Dialogue Script — บทเรียบเรียงและบทสนทนาเกม

> บทสนทนาต่อไปนี้เป็น Game Dialogue ที่เขียนขึ้นใหม่เพื่อใช้ในเกม ไม่ใช่คำประพันธ์ต้นฉบับ ส่วนคำบรรยายเหตุการณ์เป็น Adapted Narrative สรุปตามแหล่งอ้างอิง ดูข้อจำกัดและรายการอ้างอิงใน `storyboard.md`.

## scene01 — กำเนิดพลายงาม

**narrator:** ในเรือนของขุนช้าง วันทองให้กำเนิดบุตรชายและตั้งชื่อว่า พลายงาม
**wantong:** ลูกแม่…ขอให้เติบโตอย่างปลอดภัยนะ
**narrator:** พลายงามเป็นบุตรของวันทองกับขุนแผน แม้ในช่วงต้นชีวิตจะอยู่ในเรือนขุนช้าง
**wantong:** เมื่อถึงเวลา แม่จะเล่าเรื่องครอบครัวของลูกให้ฟัง

## scene02 — ความแค้นของขุนช้าง

**narrator:** หลายปีผ่านไป พลายงามเติบโตขึ้น รูปร่างหน้าตาทำให้ขุนช้างนึกถึงขุนแผน
**khunchang:** เด็กคนนี้ไม่ใช่ลูกของข้า…
**narrator:** ความคิดนั้นทำให้ขุนช้างโกรธและคิดหาทางกำจัดพลายงาม
**wantong:** ขุนช้างเงียบผิดปกติ…ฉันต้องคอยระวังลูก

## scene03 — อุบายกลางป่า

**khunchang:** ไปเดินเล่นในป่ากับข้าเถอะ พลายงาม
**phlai_ngam:** เราไปไกลจากบ้านแล้วหรือยังครับ
**narrator:** เมื่ออยู่ในที่เปลี่ยว ขุนช้างทำร้ายพลายงามจนหมดสติ แล้วทิ้งเขาไว้ใต้ขอนไม้
**narrator:** ภาพตัดออก เหลือเพียงเสียงลมและความมืด

## scene04 — ผู้ช่วยเหลือในเงามืด

**narrator:** ในความมืด มีเงาลึกลับเข้ามาช่วยยกขอนไม้ออกจากร่างพลายงาม
**hongphrai:** ฟื้นเถิด พลายงาม เจ้ายังปลอดภัย
**phlai_ngam:** ข้า…ยังมีชีวิตอยู่หรือ
**narrator:** โหงพรายช่วยให้เด็กชายฟื้น แล้วไปเข้าฝันว่าวันทองเพื่อบอกเหตุร้าย

## scene05 — ความจริงจากปากแม่

**wantong:** ลูกแม่! แม่ตามหาเจ้าแทบไม่ไหว
**phlai_ngam:** ขุนช้างพาผมเข้าป่า แล้วผมก็จำอะไรไม่ได้อีกเลย
**wantong:** พ่อของเจ้าคือขุนแผน ขุนช้างทำร้ายเจ้าเพราะคิดว่าเจ้าเป็นลูกของพ่อ
**phlai_ngam:** ถ้าเช่นนั้น ผมควรไปหาใครต่อครับ
**wantong:** แม่จะฝากเจ้าไว้ในที่ปลอดภัย แล้วชี้ทางไปหาย่าทองประศรี

## scene06 — การจากลาและฝากไว้ที่วัด

**wantong:** คืนนี้ลูกอยู่กับขรัวนากก่อนนะ พรุ่งนี้แม่จะมาหา
**khrua_nak:** อาตมาจะดูแลพลายงามให้ปลอดภัย
**phlai_ngam:** แม่จะกลับมาหาผมใช่ไหมครับ
**wantong:** แม่จะมาส่งลูกเอง และบอกทางไปหาย่า

## scene07 — เส้นทางสู่เมืองกาญจนบุรี

**wantong:** ทางนี้ไปเมืองกาญจนบุรี จงจำให้ดีและอย่าเดินหลง
**phlai_ngam:** ผมจะไปหาย่าทองประศรีตามที่แม่บอก
**wantong:** เดินทางดี ๆ นะลูก แม่จำต้องกลับไป
**narrator:** พลายงามออกเดินทางตามลำพัง โดยมีจุดหมายคือบ้านของย่า

## scene08 — พบย่าทองประศรี

**thongprasi:** หนูเป็นใคร เดินทางมาไกลเช่นนี้
**phlai_ngam:** ผมชื่อพลายงาม เป็นลูกของขุนแผนกับวันทองครับ
**thongprasi:** หลานของย่าจริงด้วย เข้ามาพักก่อนเถิด
**narrator:** ทองประศรีรับพลายงามไว้ดูแล การเดินทางช่วงนี้จบลงที่บ้านของย่า
